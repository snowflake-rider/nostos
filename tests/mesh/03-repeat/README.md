# 03. 계속 반복 — Ctrl+C로 종료

준비: [02 짧은 송수신](../02-delivery/README.md)이 먼저 통과해야 합니다.
목적: D6 → 76·B6 시험을 5초 간격으로 반복하며 누락·끊김을 관찰합니다.

```sh
bash tests/mesh/03-repeat/run.sh --send
```

`Ctrl+C` 또는 로그 약 **50 MiB**에서 종료합니다. 오류·중복·다른 조작이 감지되면 중단합니다.
단순 수신 누락은 기록하고 계속합니다. 백그라운드 서비스나 예약 작업은 설치하지 않습니다.

결과: 마지막 `SUMMARY` 경로의 `summary.json`과 `trials.csv`에서 누락 회차와 종료 원인을 봅니다.
도중 종료한 마지막 회차는 `AMBIGUOUS`일 수 있으므로 앞선 완료 회차와 구분합니다.
ON/OFF 상태는 자동 복원하지 않습니다. 정해진 시간 동안 관찰한 결과이지 무한 안정성 증명은 아닙니다.

누락·끊김이 있으면 원인을 확인합니다. 중계 효과도 확인하려면 [04 Relay 비교](../04-relay/README.md)로 갑니다.
