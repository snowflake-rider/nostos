## 0. 시작 전
- [x] STM32-1과 ESP32-76 전원이 켜져 있다.
- [x] STM32-2와 ESP32-D6 전원이 켜져 있다.
- [x] STM32-3과 ESP32-B6 전원이 켜져 있다.
- [x] XOSS 센서 이름이 `XOSS S-26518`인지 확인했다.
- [x] 사진 01: 연결된 장치 6개가 모두 보이게 전체 사진을 찍었다.

## 1. STM32-1 — FRONT / 속도·거리

- [ ] 켜자마자 대시보드가 나온다. 보정 화면은 나오지 않아야 한다.
- [ ] 자전거를 고정하고 바퀴를 돌리면 속도 `km/h`가 변한다.
- [ ] 바퀴를 계속 돌리면 거리 `km`가 증가한다.
- [ ] 온도와 습도가 `N/A`가 아니라 STM32-3의 값으로 나온다.
- [ ] 버튼 1을 누르면 `FRONT SENT ACCELERATE`가 나온다.
- [ ] 버튼 2를 누르면 `FRONT SENT DECEL`이 나온다.
- [ ] 버튼 3을 누르면 `FRONT SENT STOP`이 나온다.
- [ ] 사진 02: STM32-1 화면에 속도·거리·온도·습도가 함께 보이게 찍었다.
- [ ] 사진 03: STM32-1의 `FRONT SENT ...` 메시지를 찍었다.

## 2. STM32-2 — REAR / MPU6050·FALL

- [ ] 전원을 켠 직후 `Calibration Initialization` 화면이 나온다.
- [ ] 자전거를 똑바로 세우고 움직이지 않으면 `CALIBRATING` 게이지가 올라가고 `2.0s LEFT`가 `0.0s LEFT`까지 줄어든다.
- [ ] 약 2초 뒤 `CAL OK`가 나오고 대시보드로 이동한다.
- [ ] 대시보드에 공유된 속도·거리·온도·습도가 나온다.
- [ ] 버튼 1을 누르면 `REAR SENT ACCELERATE`가 나온다.
- [ ] 버튼 2를 누르면 `REAR SENT DECEL`이 나온다.
- [ ] 버튼 3을 누르면 `REAR SENT STOP`이 나온다.
- [ ] 사진 04: `Calibration Initialization` 화면을 찍었다.
- [ ] 사진 05: `CALIBRATING` 게이지를 찍었다.
- [ ] 사진 06: `CAL OK` 화면을 찍었다.
- [ ] 사진 07: STM32-2 대시보드 전체를 찍었다.

### 보정 실패·재시도

- [ ] STM32-2를 재부팅하고 보정 중에 장치를 움직여 `CAL REQUIRED`를 확인했다.
- [ ] 버튼 1을 누르는 동안 `HOLD BUTTON 1`과 시간이 올라간다.
- [ ] 버튼 1을 중간에 놓으면 게이지가 0으로 돌아간다.
- [ ] 버튼 1을 다시 3초 동안 누르면 `Calibration Initialization`부터 다시 시작한다.
- [ ] 장치를 가만히 두고 재보정이 성공하는지 확인했다.
- [ ] 사진 08: `CAL REQUIRED` 화면을 찍었다.
- [ ] 사진 09: 버튼을 누른 채 `1.8s` 근처의 게이지를 찍었다.

## 3. STM32-3 — CENTER / DHT11

- [ ] 켜자마자 대시보드가 나온다. 보정 화면은 나오지 않아야 한다.
- [ ] 온도 `°C`가 `N/A`가 아닌 정상적인 값으로 나온다.
- [ ] 습도 `%`가 `N/A`가 아닌 정상적인 값으로 나온다.
- [ ] 대시보드에 공유된 속도와 거리가 나온다.
- [ ] 버튼 1을 누르면 `CENTER SENT ACCELERATE`가 나온다.
- [ ] 버튼 2를 누르면 `CENTER SENT DECEL`이 나온다.
- [ ] 버튼 3을 누르면 `CENTER SENT STOP`이 나온다.
- [ ] 사진 10: STM32-3 화면에 온도·습도가 보이게 찍었다.
- [ ] 사진 11: STM32-3의 `CENTER SENT ...` 메시지를 찍었다.

## 4. 세 장치 데이터 공유

- [ ] 세 화면의 속도와 거리가 같은 값으로 보인다.
- [ ] 세 화면의 온도와 습도가 같은 값으로 보인다.
- [ ] 값이 바뀐 뒤 3초 안에 다른 화면에도 반영된다.
- [ ] XOSS를 멈추고 3초 이상 지나면 오래된 속도를 계속 정상값처럼 표시하지 않는다.
- [ ] XOSS를 다시 돌리면 속도·거리가 다시 표시된다.
- [ ] 사진 12: STM32 3개의 화면이 동시에 보이게 나란히 찍었다.

## 5. FALL 공유 — 마지막에 안전하게 테스트

> 실제로 타다가 넘어지지 않습니다. 자전거와 전자장치를 보호한 상태에서 정지 테스트만 합니다.

- [ ] STM32-2에서 통제된 FALL 테스트를 진행했다.
- [ ] STM32-2 화면 전체에 삼각형과 `FALL DETECTED!`가 나온다.
- [ ] STM32-1과 STM32-3에도 `FALL DETECTED!`가 전달된다.
- [ ] FALL 상태가 일반 버튼 메시지보다 먼저 처리된다.
- [ ] 사진 13: 세 화면의 FALL 경고가 같이 보이게 찍었다.
