## 과거 기록을 읽을 때

이관된 기존 문서는 원문을 보존하고 상단에 이관 안내를 붙였습니다. 당시 명칭·절대 경로·검증 시점이 남아 있으므로, 현재 실행 명령은 [팀원 시작](00-team/START.md)을 기준으로 합니다.

기존 `STATUS.md`의 미확인 항목과 더 나중의 `verified/` 결과는 서로 다른 시점을 기록합니다. 과거의 PASS는 새 펌웨어 Flash나 새 보드의 성공을 자동으로 증명하지 않습니다.

[이관된 전체 원문 문서 목록](04-records/IMPORTED-DOCUMENTS.md)에서 기존 자료를 빠짐없이 찾을 수 있습니다.
