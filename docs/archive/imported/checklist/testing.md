## 동작 확인 체크리스트

### 낙상 감지

- [ ] 넘어짐 감지 후 일정 시간이 지나면 LED가 빨간색으로 점멸한다.
- [ ] 넘어짐 감지 후 일정 시간이 지나면 부저가 빠른 주기로 울린다.

### 후방 장애물 감지

- [ ] 초음파 센서가 후방 장애물을 감지하면 LED가 노란색으로 점멸한다.
- [ ] 후방 장애물 감지 시 부저가 여러 차례 울린다.
- [ ] 장애물 감지가 해제되면 LED가 녹색 상태로 돌아온다.
