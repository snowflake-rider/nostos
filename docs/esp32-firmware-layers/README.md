# ESP32 펌웨어 Layer 1~8 확장

ESP32 통신 기능을 한 단계씩 확장한 구조다.

| Layer | 핵심 역할 |
| --- | --- |
| [Layer 1](layer-1.md) | BLE 이름 Advertising |
| [Layer 2](layer-2.md) | 연결 가능한 GATT Server |
| [Layer 3](layer-3.md) | BLE Advertising 스캔 |
| [Layer 4](layer-4.md) | GATT + Advertising + Scan 동시 실행 |
| [Layer 5](layer-5.md) | 20-byte 사용자 패킷 송수신 |
| [Layer 6](layer-6.md) | TTL 기반 사용자 패킷 전달 |
| [Layer 7](layer-7.md) | 표준 Bluetooth Mesh |
| [Layer 8](layer-8.md) | STM32 UART ↔ Mesh 연결 |
| [Layer 8 RIDAR](layer8-ridar.md) | Layer 8 + RPLIDAR C1 진단 |
