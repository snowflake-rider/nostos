# 06. Mesh용 두 바이트 만들기

[← 이전](05-uart.md) · [목차](README.md) · [다음 →](07-receive.md)

**ESP32는 받은 ID 앞에 형식의 버전 번호를 붙입니다.**

```text
UART에서 받은 것:  [13]
Mesh로 보낼 내용:  [01 13]
                    │  └─ 정지 요청 ID
                    └──── 형식 버전 1
```

버전은 **어떤 형식의 약속을 쓰는지** 구별하는 번호입니다. 현재는 버전 1입니다.

이 두 바이트를 **앱 payload**, 즉 우리 프로그램이 Mesh에 맡기는 내용이라고 부릅니다.

**무선 패킷 전체가 2바이트라는 뜻은 아닙니다.**

## 어디로 보낼까?

Mesh는 ESP32끼리 무선으로 전달하는 통신입니다. 같은 네트워크·그룹 등의 설정을 맞춘 장치가 대상이며, 주변의 모든 Bluetooth 기기로 보내는 것은 아닙니다.
