# 08. 상대 STM32에서 소리 내기

[← 이전](07-receive.md) · [목차](README.md)

**상대 ESP32가 꺼낸 번호를, 상대 STM32가 다시 읽습니다.**

```text
ESP32 B ── UART [13] ──→ STM32 B
                           ↓ 정지 요청으로 해석
                       저장된 음원 선택
                           ↓ SPI
                       VS1003B → 스피커
```

## 소리는 어디서 올까?

STM32 B는 자기 장치에 저장된 **정지 요청 음원**을 선택합니다. A가 음성 파일을 무선으로 보낸 것이 아닙니다.

오디오가 정상적으로 준비되어 있고 다른 음원이 재생 중이 아닐 때 재생할 수 있습니다. 현재 코드에서는 재생 중 들어온 새 재생 요청은 무시합니다.

정지 요청은 음성 알림입니다. **브레이크를 자동으로 잡거나 LED·부저를 바꾸는 명령이 아닙니다.**
