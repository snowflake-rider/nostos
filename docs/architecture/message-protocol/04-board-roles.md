# 04. STM32와 ESP32의 역할

[← 이전](03-message-id.md) · [목차](README.md) · [다음 →](05-uart.md)

**한 라이더의 장치 안에서도 두 보드의 역할이 다릅니다.**

```text
STM32                     ESP32
내용을 결정한다  ───────→  무선으로 전달한다
```

STM32는 버튼·센서 입력을 처리하고 **어떤 메시지를 보낼지** 정합니다.

ESP32는 그 메시지를 받아 다른 라이더의 ESP32로 전달합니다.

지금은 STM32가 정지 요청을 선택했다고 가정합니다. 실제 버튼 배선·시험 모드는 나중에 봅니다.
