# 05. UART로 한 바이트 보내기

[← 이전](04-board-roles.md) · [목차](README.md) · [다음 →](06-mesh-payload.md)

**같은 라이더의 STM32와 ESP32는 선으로 데이터를 전달합니다.**

그 통신 방식이 **UART**입니다.

```text
STM32 ── UART ──→ ESP32
          [13]
```

## 지금 보내는 것은 하나

STM32는 정지 요청 번호 `0x13`을 **1바이트**로 보냅니다.

`[13]`은 16진수 바이트 하나를 보기 쉽게 쓴 것입니다. 대괄호는 보내지 않습니다.

> 숫자 `0x13`과 글자 두 개로 된 문자열 `"13"`은 다릅니다. 문자열이나 줄바꿈을 보내면 안 됩니다.
