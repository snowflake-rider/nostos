# 07. 받은 메시지 검사하기

[← 이전](06-mesh-payload.md) · [목차](README.md) · [다음 →](08-output.md)

**상대 ESP32는 받은 내용이 약속에 맞는지 확인합니다.**

## 세 가지 확인

1. 정확히 **2바이트**인가?
2. 앞의 버전이 **01**인가?
3. 뒤의 ID가 **우리가 정한 메시지 번호**인가?

모두 맞으면 ID를 꺼냅니다. 하나라도 다르면 이 이벤트로 받아들이지 않습니다.

```text
[01 13] ── 검사 통과 ──→ [13]
[02 13] ── 버전 다름 ──→ 거부
```

**길이·버전·번호 검사이지, 실제로 안전한 상황인지 판단하는 검사는 아닙니다.**
