# 01. 메시지와 프로토콜

[목차](README.md) · [다음: 전체 흐름 →](02-one-message.md)

**이번 페이지에서는 두 단어만 구분합니다.**

## 메시지는 전달할 내용

라이더 A가 B에게 **“잠깐 멈추자”**고 알리고 싶습니다.

이 전달 내용이 **메시지**입니다.

## 프로토콜은 주고받는 약속

보내는 장치와 받는 장치가 같은 내용을 서로 다르게 해석하면 안 됩니다.

그래서 **어떻게 표현하고 읽을지 미리 정한 약속**이 필요합니다. 이것이 **메시지 프로토콜**입니다.

> 메시지 = 내용 / 프로토콜 = 그 내용을 주고받는 약속
