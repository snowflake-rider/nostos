# 03. 정지 요청에 번호 붙이기

[← 이전](02-one-message.md) · [목차](README.md) · [다음 →](04-board-roles.md)

**우리 프로젝트는 문장 대신 미리 정한 번호를 보냅니다.**

## 번호 하나만 기억하기

```text
정지 요청 = 0x13
```

이 번호가 **메시지 ID**입니다. 무엇을 뜻하는지 구별하는 번호입니다.

`0x`는 16진수 표기라는 표시입니다. `0x13`은 십진수 13과 다르지만, 지금은 변환 계산을 외울 필요는 없습니다.

`0x13`이 원래부터 정지라는 뜻은 아닙니다. **이 프로젝트에서 그렇게 정했습니다.**

## 코드에서는 이렇게 이름을 붙입니다

```c
MSG_STOP_REQUEST = 0x13,
```

왼쪽은 코드에서 부르는 이름, 오른쪽은 실제 번호입니다. [message_type.h](../../../libs/protocol/message_type.h)의 한 줄이며, 지금은 `enum` 전체를 몰라도 됩니다.
