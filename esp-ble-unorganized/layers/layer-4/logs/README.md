# Layer 4 logs

`bootload.sh`와 `bootload-pair.sh`가 생성하는 실행 기록을 저장한다.

- one-board: `esp32s3-layer-4-dual-role-YYYYMMDDTHHMMSS-KST.log`
- pair: `esp32s3-layer-4-dual-role-pair-YYYYMMDDTHHMMSS-KST.log`
- optional Mac scan: `esp32s3-layer-4-over-air-adv-YYYYMMDDTHHMMSS-KST.log`

Build, Flash, local runtime, 실제 peer reception은 서로 다른 검증 단계다.
